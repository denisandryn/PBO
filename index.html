    Struktur Hirarki Class

    Aplikasi ini mendemonstrasikan Object-Oriented Programming (OOP) menggunakan Javascript ES6 Class. Class AdminUser dan RegularUser mewarisi sifat dasar dari Superclass User.

    Superclass / Base Class
    Class User
      Properti: id, username, email, role, avatar, bio Method: getProfile(), setProfile(), checkPassword()
    Subclass / Derived Classes
    AdminUser & RegularUser
      Menggunakan keyword extends User Menggunakan super(...) untuk inisialisasi parent AdminUser: Menambahkan method CRUD (createUser, updateUser, deleteUser) RegularUser: Terbatas hanya aksi Read & Update Profil sendiri

    Implementasi Source Code JS:

    // 1. Superclass (Parent)
class User {
    constructor(id, username, password, email, role = 'user', avatar = '', bio = '') {
        this.id = id;
        this.username = username;
        this.password = password;
        this.email = email;
        this.role = role;
        this.avatar = avatar || `https://api.dicebear.com/7.x/avataaars/svg?seed=${username}`;
        this.bio = bio;
    }
    setProfile(email, avatar, bio) {
        this.email = email;
        this.avatar = avatar;
        this.bio = bio;
    }
}

// 2. Subclass Admin (Mewarisi User)
class AdminUser extends User {
    constructor(id, username, password, email, avatar, bio) {
        super(id, username, password, email, 'admin', avatar, bio); // Pewarisan
        this.permissions = ['CREATE', 'READ', 'UPDATE', 'DELETE', 'MANAGE_USERS'];
    }
    createUser(userList, newUserObj) { /* Logic Tambah User */ }
    updateUser(userList, targetId, updatedData) { /* Logic Edit User */ }
    deleteUser(userList, targetId) { /* Logic Hapus User */ }
}

// 3. Subclass Regular User (Mewarisi User)
class RegularUser extends User {
    constructor(id, username, password, email, avatar, bio) {
        super(id, username, password, email, 'user', avatar, bio); // Pewarisan
        this.permissions = ['READ', 'UPDATE_SELF'];
    }
}
